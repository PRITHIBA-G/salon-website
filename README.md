# Salon Website
A modern and responsive multi-page salon website developed using HTML, CSS, and JavaScript. This project demonstrates responsive web design, clean layouts, and an intuitive user experience through a professional salon website.


## Live Demo
[View Website](https://voluble-sprite-bae115.netlify.app/)

## Overview
This project was developed as a sample front-end website to demonstrate responsive web design and modern UI development. It includes multiple pages commonly found in professional salon websites.

## Features
- Responsive design
- Multi-page website
- Modern and clean UI
- Services section
- Transformation gallery
- About page
- Contact page
- Consistent navigation

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
```text
salon-website/

├── style.css

```

## Getting Started
```bash
git clone https://github.com/PRITHIBA-G/salon-website.git
cd salon-website
```

Open `index.html` in your browser.
